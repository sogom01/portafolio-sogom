# Security Policy

## Reporting a Vulnerability

Si descubres una vulnerabilidad de seguridad en este portafolio o en
cualquiera de sus proyectos asociados, por favor **no abras un issue
público**.

Reporta el problema de forma responsable a:

- **Email:** sog981@gmail.com
- **Asunto recomendado:** `[SECURITY] <breve descripción>`

Por favor incluye:

1. Descripción del problema.
2. Pasos para reproducirlo (PoC si aplica).
3. Impacto estimado.
4. Tu nombre o handle si deseas crédito en el agradecimiento público.

Me comprometo a:

- Acusar recibo en menos de 48 horas.
- Mantener confidencialidad mientras se trabaja en la mitigación.
- Reconocer públicamente tu contribución (a menos que prefieras anonimato).
